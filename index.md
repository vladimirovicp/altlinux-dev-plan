# altlinux.dev
## Цель сайта
Создать платформу, которая поможет разработчикам:
Участвовать в развитии экосистемы altlinux


## Задачи :
1. Подробное ознакомление с проектами
2. Новостная лента
3. Быстрый старт
4. Менторство
5. Список минимальных знаний, которые необходимы, что бы запросить ментора. Быть может перечень тем которые необходимо изучить(ознакомиться).
6. Разместить на ресурсе все важные ссылки, на сообщества, докумментацию, уроки, видеоуроки и т.д.
7. ссылки на все дистрибутивы - предполагаю это getalt

### Детализация задач

* Быстрый старт, включает в себя ссылки на:
    * Гайды «Первые шаги с ALT Linux» Базовые гайды
    * докумментацию
    * видеолекции
* Менторство 
    * Изучение минимальных требований (список требований, материалов)
    * Тестовое задание
    * Проверка базовых знаний (можно автоматизировать через тесты на сайте)
    * Профили менторов, страница доступных менторов
* Ссылки
    * Структурированный каталог ресурсов (документация, видео, дистрибутивы)



## Главная страница
1. Логотип : ALT Linux + слоган
2. Меню
    * Проекты
    * Новости
    * Обучение
    * Менторство
    * Пакеты?
    * Взаимодействие
3. main
    * hero - основная информация о проекте 
        * Добро пожаловать в сообщество разработчиков ALT Linux
        * «Изучайте проекты, улучшайте код, находите менторов и участвуйте в развитии экосистемы»
        * Более 20 лет «Базальт СПО» поддерживает развитие ежедневно обновляемого репозитория (хранилища) свободных программных пакетов проекта Sisyphus («Сизиф»). Проект ведет ALT Linux Team — международная, преимущественно русскоязычная команда разработчиков свободного программного обеспечения. Большинство разработчиков «Базальт СПО» участвуют в работе ALT Linux Team, репозиторий работает на серверах, принадлежащих компании. Весь код, созданный участниками ALT Linux Team, распространяется под свободными лицензиями: его можно использовать в любых целях, изучать и вносить изменения, распространять. Сотрудничество по принципу «вклад каждого — достояние всех» позволяет создавать программные продукты на основе лучших мировых достижений.
    * Блок «Популярные проекты»
        * Заголовок : «Проекты, которые вы можете улучшить»
        * 3 - 4 проекта, либо карусель(слайдер) проектов
        * Кнопка : «Все проекты» (ссылка на каталог проектов).
    * Блок «Быстрый старт»
        * Заголовок : «Новичок? Начните здесь!»
        * Изучите базовый гайд (ссылка на документацию).
        * Выберите проект для доработки.
        * Задания для обучения
        * Кнопка : «Посмотреть руководство» (ссылка на раздел Быстрый стар).
    * Блок «Новости и события»
        * Заголовок : Новости
        * 3 - 4 последних новостей
        * Кнопка : «Все новости» (ссылка на архив).
    * Блок «Менторство»
        * Заголовок : «Станьте частью сообщества»
        * ученик
            * Список минимальных требований
            * Кнопка: «Найти ментора» или «Подать заявку»
        * ментор
            * документация как одобрить себя и оказаться в менторах, а так же как снять свою кандидатуру
    * Блок «Ссылки и ресурсы»
        * Заголовок : «Важные ресурсы»
        * Категории :
            * Документация (официальные гайды, man-страницы)
            * Сообщества (форум, чат, GitHub/GitLab)
            * Видеоуроки (YouTube-канал, rutube,  курсы)
    * Футер
        * Контакты : Email, соцсети, ссылка на GitHub.
        * Юридическая информация : Лицензии, политика конфиденциальности.
        * Карта сайта : Важные разделы.
