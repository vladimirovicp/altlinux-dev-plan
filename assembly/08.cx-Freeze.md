# Сборка cx-Freeze

https://pypi.org/project/cx-Freeze/

https://github.com/marcelotduarte/cx_Freeze/tree/main

https://github.com/marcelotduarte/cx_Freeze/releases/tag/8.3.0


Создаём cx_Freeze.spec и накидываем по минимуму


```bash
rpmbuild -ba ~/RPM/SPECS/cx_Freeze.spec
```

```bash

$ rpmbuild -ba ~/RPM/SPECS/cx_Freeze.spec
ошибка: failed build dependencies:
        python3-module-setuptools is needed by python3-module-cx_Freeze-8.3.0-alt1
        python3-devel is needed by python3-module-cx_Freeze-8.3.0-alt1
```

говорит, что бы в систему установили 

```bash
apt-get install python3-module-setuptools python3-devel
```
