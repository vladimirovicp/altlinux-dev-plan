Клонируем libpqxx

```bash
git clone https://github.com/jtv/libpqxx.git
```

```bash
./configure --prefix=/opt/libpqxx
```

![image](img/04.libpqxx-v2/2025-06-22_205909.png)

```bash
sudo apt-get install build-essential
sudo apt install cmake
```

![image](img/04.libpqxx-v2/2025-06-22_210916.png)

Теперь нудно отпределить, где содержится libpq-fe.h, которого нам нехватает

```bash
sudo apt install apt-file

sudo apt-file update

apt-file search libpq-fe.h
```

![image](img/04.libpqxx-v2/2025-06-22_212854.png)

```bash
sudo apt install libpq-dev
```

![image](img/04.libpqxx-v2/2025-06-22_213843.png)



```bash
make
```

![image](img/04.libpqxx-v2/2025-06-22_214310.png)


```bash 
sudo make install
```
