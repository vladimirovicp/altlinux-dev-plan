# Сборка htmldoc

Пакет потерял своего мантейнера и попал по правам @nobody
Заброшенные пакеты можно посмотреть [тут](https://watch.altlinux.org/pub/watch/by-leader/%40nobody.txt).

Upstream располагается [тут](https://github.com/michaelrsweet/htmldoc)
sisyphus [тут](https://packages.altlinux.org/ru/sisyphus/srpms/htmldoc/)
git altlinux [тут](https://git.altlinux.org/gears/h/htmldoc.git)

Версия в sisyphus 1.9.16, в upstream 1.9.21

Для начала соберем рабочую версию

```bash
gear-rpm -ba
предупреждение: Macro %_fontsdir not found
предупреждение: Macro %_fontpathdir not found
предупреждение: Macro %_fontsdir not found
предупреждение: Macro %_fontsdir not found
предупреждение: Macro %_fontsdir not found
предупреждение: Macro %_fontsdir not found
предупреждение: Macro %_fontsdir not found
предупреждение: Macro %_fontsdir not found
предупреждение: Macro %_fontsdir not found
предупреждение: Macro %_fontpathdir not found
предупреждение: Macro %_fontsdir not found
предупреждение: Macro %_fontpathdir not found
ошибка: Macro %_fontsdir not found
ошибка: строка 131:     /usr/sbin/chkfontpath -q -r %_fontsdir/htmldoc ||:
```
Ошибка, которую мы видим при сборке пакета htmldoc в ALT Linux с помощью gear-rpm, связана с тем, что в используемом .spec-файле присутствуют макросы RPM (%_fontsdir, %_fontpathdir), которые не определены в системе ALT Linux.


Для этого добавим в .rpmmacros

```bash
%_fontsdir	%{_datadir}/X11/fonts
%_fontpathdir	%_sysconfdir/X11/fontpath.d
```

[Ссылка на Spec/Предопределенные макросы](https://www.altlinux.org/Spec/%D0%9F%D1%80%D0%B5%D0%B4%D0%BE%D0%BF%D1%80%D0%B5%D0%B4%D0%B5%D0%BB%D0%B5%D0%BD%D0%BD%D1%8B%D0%B5_%D0%BC%D0%B0%D0%BA%D1%80%D0%BE%D1%81%D1%8B)


Запускаем сборку

```bash
gear-rpm -ba
ошибка: failed build dependencies:
        rpm-build-fonts   is needed by htmldoc-1.9.16-alt2
        libfltk-devel   is needed by htmldoc-1.9.16-alt2
        libgnutlsxx-devel   is needed by htmldoc-1.9.16-alt2
        libXcursor-devel is needed by htmldoc-1.9.16-alt2
        libXfixes-devel is needed by htmldoc-1.9.16-alt2
        libXinerama-devel is needed by htmldoc-1.9.16-alt2
        libXpm-devel is needed by htmldoc-1.9.16-alt2

```

Ошибка указывает, что при попытке собрать пакет htmldoc с помощью gear-rpm -ba не хватает зависимостей времени сборки (BuildRequires), перечисленных в .spec-файле.

установим необходимые пакеты

```bash

apt-get install rpm-build-fonts libfltk-devel libgnutlsxx-devel libXcursor-devel libXfixes-devel libXinerama-devel libXpm-devel

```

Запускаем сборку и нарываемся на ошибку

```
<command-line>: error: "_FORTIFY_SOURCE" redefined [-Werror]
```

Причина:
Система ALT Linux автоматически задаёт _FORTIFY_SOURCE=2 через %optflags, а проект повторно определяет его в CXXFLAGS (обычно в Makedefs.in или configure.ac).
