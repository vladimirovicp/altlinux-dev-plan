# gpui

- **Описание проекта**
    - Краткое и понятное описание цели проекта, его задач и преимуществ.
        - GPUI — утилита с открытым исходным кодом для управления групповыми политиками в ALT-Linux.
        - Редактор групповой политики предоставляет способ настройки компьютера, присоединенного к домену Active Directory.
        - Графического редактора групповых политик в доменной инфраструктуре MS AD или Samba DC.
        - GPUI является частью альтернативного решения компании «Базальт СПО» по реализации доменной инфраструктуры Active Directory под Linux. <br> Приложение поддерживает работу в доменной инфраструктуре MS AD или Samba DC.

    - Основные изменения
        - Новые функции
            - Поддержка работы с Samba 4.20.4.
            - Поддержка версий политик (GPO) - редактирование политик меняет версию в объекте г.п. (GPO).
            - Система логирования.
        - Исправленные ошибки
            - Изменения версии объекта GPO происходит как после запуска GPUI, так и после редактирования г.п., что позволяет gpupdate применять корректную версию объекта групповой политики.
            - Исправлено применение политик, основанный на списке URL, на Windows-клиенте.
            - Отлажена настройка параметров, в частности, разделов Управление пакетами, Настройка механизма копирования файлов, Установка и удаление программ.
            - Улучшено взаимодействие с интерфейсом, в том числе настройка параметров для Firefox.
        - Исправленные ошибки (bugzilla)
            - Неправильно сохраняет / отображает значение комментария ([47576](https://bugzilla.altlinux.org/47576))
            - Windows-клиент не обрабатывает GPT.INI, сформированный GPUI (лишние символы при отображении заголовка DisplayName / в окне настройки скриптов) ([51466](https://bugzilla.altlinux.org/51466)) <br> Добавлен плагин для обработки GPT.INI-файлов (для работы политик Скриптов).
            - GPT.INI поле Version не соответствует версии политики ([51451](https://bugzilla.altlinux.org/51451))

## Info

В версии 0.2.17 появились настройки системы (preferences): политики файлов (files), папок (folders), переменных (environment variables), значков рабочего стола (shortcuts), ключа реестра (registry -> registry key), ini файлов (ini files), общих каталогов (network shares), сетевых дисков (mapped drives).

Добавлена поддержка горячих клавиш. Улучшена работа с деревом шаблонов.
