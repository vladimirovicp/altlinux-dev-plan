## rpmdevtools

Этот пакет содержит скрипты и файлы поддержки (X)Emacs, предназначенные для помощи в разработке RPM-пакетов.
Пакет предоставляет набор инструментов для упрощения работы с RPM-пакетами — от создания структуры директорий до проверки целостности и управления версиями.

### Основные утилиты в составе пакета:

> * **rpmdev-setuptree** — Создаёт стандартное дерево сборки RPM в домашней директории пользователя (~/RPM/{BUILD, RPMS, SOURCES, SPECS, SRPMS}).
>
> * **rpmdev-diff** — Сравнивает содержимое двух архивов (например, .tar.gz, .rpm).
>
> * **rpmdev-newspec** — Генерирует новый .spec-файл на основе шаблона (поддерживаются шаблоны для разных языков и фреймворков).
>
> * **rpmdev-rmdevelrpms** — Находит (и при необходимости удаляет) "разработочные" RPM-пакеты (например, *-devel, *-debuginfo).
>
> * **rpmdev-checksig** — Проверяет подписи пакетов, используя альтернативное хранилище ключей RPM.
>
> * **rpminfo** — Выводит информацию о исполняемых файлах и библиотеках в пакете.
>
> * **rpmdev-md5 / rpmdev-sha\*** — Вычисляет контрольные суммы (MD5, SHA1, SHA256 и др.) для всех файлов в архиве.
>
> * **rpmdev-vercmp\*** — Сравнивает версии пакетов в формате RPM (полезно для условий в .spec).
>
> * **rpmdev-wipetree\*** — Очищает все файлы в директориях, созданных rpmdev-setuptree.
>
> * **rpmdev-extract\*** — Распаковывает архивы разных форматов (аналог tar xvf, но с поддержкой .zip, .rpm, .deb и др.).
>
> * **rpmdev-bumpspec\*** — Автоматически увеличивает номер релиза (Release:) в .spec-файле.

### Ключевые возможности:
1.Автоматизация рутинных задач:
*   **rpmdev-newspec** избавляет от ручного написания .spec-файлов.
*   **rpmdev-bumpspec** ускоряет обновление версий пакетов.

2.Анализ пакетов:
* **rpminfo** показывает зависимости библиотек/исполняемых файлов.
* **rpmdev-checksig** помогает в аудите безопасности.

3.Работа с архивами:
* **rpmdev-extract** поддерживает даже экзотические форматы (например, .7z).
* **rpmdev-diff** выявляет изменения между версиями исходников.

4.Очистка системы:
* **rpmdev-rmdevelrpms** удаляет ненужные dev-пакеты, экономя место.
