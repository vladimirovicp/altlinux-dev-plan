
## sizeof

**sizeof** — это оператор (не функция!), который возвращает размер в байтах типа данных или переменной на текущей платформе и компиляторе.

1. использования sizeof с размером типа данных

```C
#include <stdio.h>

int main() {
    printf("Размер int: %zu байт\n", sizeof(int)); // Размер int: 4 байт
    printf("Размер double: %zu байт\n", sizeof(double)); //Размер double: 8 байт
    printf("Размер char: %zu байт\n", sizeof(char)); //Размер char: 1 байт
    return 0;
}
```

%zu — спецификатор формата для size_t, который возвращает sizeof. 

2. использования sizeof с переменной:
```C
int x = 42;
printf("Размер переменной x: %zu байт\n", sizeof x); //Размер переменной x: 4 байт
```

3. использования sizeof с массивами
```C
int arr[10];
printf("Размер массива arr: %zu байт\n", sizeof(arr)); // Размер массива arr: 40 байт  (если int = 4 байта)
```

4. использования sizeof с выражением:
```C
int a = 2;
double b = 3;
printf("Размер выражения a + b: %zu байт\n", sizeof(a + b)); //Размер выражения a + b: 8 байт
```
a (int) автоматически приводится к double при сложении с b




```c
    int a = 2;
    int b = 3;
    printf("%d",b / a); // 1
    printf("%zu\n", sizeof(a + b));// 4

    printf("%g\n",(double)b / a); // 1.5
    printf("%zu\n", sizeof((double)a + b));// 8
```

## Условный оператор (оператор условного перехода, оператор ветвления)

```c
#include <stdio.h>
#include <stdlib.h>

int main()
{
    int max;
    int a = 3, b=7;
    
    if(a>b) printf("a>");
    else    printf("b>");

    //b>

    return 0;
}
```

```c
#include <stdio.h>
#include <stdlib.h>

int main()
{
    int max;
    int a = 3, b=7;
    
    if(a>b){
        printf("a>\n");
        max = a;
        }
    else{
        printf("b>\n");
        max = b;
    };

    printf("%d\n",max); //b>

}
```
