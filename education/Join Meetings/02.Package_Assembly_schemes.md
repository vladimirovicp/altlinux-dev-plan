# 02.Схемы сборки пакетов

На https://git.altlinux.org/ есть два вида репозиториев GEAR и SRPMs


## Cборка с помощью rpm

Для начала нужно создать структуру каталогов

Структуру каталогов можно создать с помощью rpmdevtools 

```bash
apt-get install rpmdevtools
```

используя утилиту rpmdev-setuptree 

```bash
$ rpmdev-setuptree
```

или прописав каталоги ручками
```bash
mkdir -p ~/RPM/{BUILD,BUILDROOT,RPMS,SOURCES,SPECS,SRPMS}
```

## Отправляем пакет


Сборочница пользуется с sisyphus_check ссылка_на_пакет.src.rpm

```bash
apt-get install sisyphus_check
```

alt-rpmkeys - используется для проверки цифровых подписей RPM-пакетов из репозиториев ALT Linux

```bash
apt-get install alt-rpmkeys
```

```bash
apt-get install alt-rpmkeys-utils
```

Обрати внимание на rpmsign --addsign /path_package.src.rpm

```bash
rpm -K /home/NAME/RPM/SRPM/gnome-calendar-48.1-alt2.src.rpm
sisyphus_check --file /home/NAME/RPM/SRPM/gnome-calendar-48.1-alt2.src.rpm
rsync /home/NAME/RPM/SRPM/gnome-calendar-48.1-alt2.src.rpm girar:
ssh girar task add srpm gnome-calendar-48.1-alt2.src.rpm
ssh girar task run
girar-show 395982
```

Последние изменения в сборочных заданиях

https://packages.altlinux.org/ru/tasks/?task_state=Running

Рассмотрим https://git.altlinux.org/srpms/g/gnome-calendar.git

```bash
git clone https://git.altlinux.org/srpms/g/gnome-calendar.git
```

```bash
gear-srpmimport /home/localadmin/RPM/SRPMS/gnome-calendar-48.0.1-alt1.src.rpm

git log -- gnome-calendar.spec
```

```bash

```

## Cборка с помощью gear

На примере https://packages.altlinux.org/ru/sisyphus/srpms/magnus/

git: https://git.altlinux.org/gears/m/magnus.git

```bash
git clone https://git.altlinux.org/gears/m/magnus.git
```

Запускаем сборку
```bash
gear-rpm -ba
WARNING: %python3_build is deprecated and will be removed in future, please use %pyproject_build instead
WARNING: %python3_install is deprecated and will be removed in future, please use %pyproject_install instead
ошибка: failed build dependencies:
        python3-module-distutils-extra is needed by magnus-1.0.3-alt2
```

```
WARNING: %python3_build is deprecated and will be removed in future, please use %pyproject_build instead
WARNING: %python3_install is deprecated and will be removed in future, please use %pyproject_install instead
```
Эти предупреждения не ломают сборку, но указывают, что вы используете устаревшие макросы. В новых версиях ALT Linux (и в целом в современных сборочных системах Python) рекомендуется использовать макросы на основе pyproject.toml

Ошибка зависимостей
```
ошибка: failed build dependencies:
        python3-module-distutils-extra is needed by magnus-1.0.3-alt2
```

Пакет python3-module-distutils-extra отсутствует в системе или больше не поддерживается.

```bash
apt-get install python3-module-distutils-extra
gear-rpm -ba
```

Все прекрасно собралось

Самая магия находится тут .gear/

Посмотрим rules
```
spec: .gear/magnus.spec
tar: @version@:.
diff: @version@:. . exclude=.gear exclude=magnus.spec
```

Указывает где лежит spec: .gear/magnus.spec, по умолчанию в корне

tar: @version@:. - говорит о том что мы берем тег @version@ и упаковываем его в tar

Далее сравниваем, что у нас в репозитории с текущим тегом и получаем некий файлик


```bash
rpm -qpl /home/localadmin/RPM/SRPMS/magnus-1.0.3-alt2.src.rpm
magnus-1.0.3-alt2.patch
magnus-1.0.3.tar
magnus.spec

```

Попробуем собрать данный пакет.

Берем и клонируем проект с апстрима

```bash
git clone https://github.com/stuartlangridge/magnus mangus.upstream

```

Из апстрима к нам прилетели теги, посмотрим на них
```bash
git tag
```

клонируем апстрим, называем sisyphus и вытягиваем тег

```bash
git checkout -b sisyphus 1.0.3
```

Не вносил изменениф в виде коммитов
```bash
gear-rpm -ba --commit
```

```bash
[localadmin@hp-83084 .gear]$ add_changelog magnus.spec

```

```bash
[localadmin@hp-83084 mangus.upstream]$ gear-update-tag 1.0.3
```
данное действие приведет к появлению в gear/ папки tags/list


```bash
[localadmin@hp-83084 .gear]$ git add .

[localadmin@hp-83084 .gear]$ gear-rpm -ba
gear: No specfiles found

```

gear собирает всегда из последнего коммита опция --commit делаем временный коммит из текущих изменений которые заданы у нас в gear репозитории

```bash

 ```

 ```bash

```

gear-commit это тоже самое, что и git commit но только с автоматической генерацией чейнжлога

