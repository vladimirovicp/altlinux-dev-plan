# 02.Схемы сборки пакетов

На https://git.altlinux.org/ есть два вида репозиториев GEAR и SRPMs


## Cборка с помощью rpm

Для начала нужно создать структуру каталогов

Структуру каталогов можно создать с помощью rpmdevtools 

```bash
apt-get install rpmdevtools
```

используя утилиту rpmdev-setuptree 

```bash
$ rpmdev-setuptree
```

или прописав каталоги ручками
```bash
mkdir -p ~/RPM/{BUILD,BUILDROOT,RPMS,SOURCES,SPECS,SRPMS}
```

## Отправляем пакет


Сборочница пользуется с sisyphus_check ссылка_на_пакет.src.rpm

```bash
apt-get install sisyphus_check
```

alt-rpmkeys - используется для проверки цифровых подписей RPM-пакетов из репозиториев ALT Linux

```bash
apt-get install alt-rpmkeys
```

```bash
apt-get install alt-rpmkeys-utils
```

Обрати внимание на rpmsign --addsign /path_package.src.rpm

```bash
rpm -K /home/NAME/RPM/SRPM/gnome-calendar-48.1-alt2.src.rpm
sisyphus_check --file /home/NAME/RPM/SRPM/gnome-calendar-48.1-alt2.src.rpm
rsync /home/NAME/RPM/SRPM/gnome-calendar-48.1-alt2.src.rpm girar:
ssh girar task add srpm gnome-calendar-48.1-alt2.src.rpm
ssh girar task run
girar-show 395982
```
